Included hidden on the landing page, where any Sign in button opens it in place; included visible on /login/, so that page simply IS the dialog (it is where a protected URL sends a signed-out visitor, and it works with no JavaScript). `standalone` means it is the page itself: there is nothing behind it to return to, so the x goes to the front page instead of closing. A wrong password re-renders the landing page with this reopened (data-modal-autoopen) and the error inside it, keeping the typed username and the "next" destination. It is deliberately the system's own door and not a generic login: the mark and the name are in the head, and the one line of copy says the thing a visitor actually needs - that there is one sign-in and it takes each role to its own portal. {% endcomment %}
